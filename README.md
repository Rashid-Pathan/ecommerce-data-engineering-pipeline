# E-Commerce Data Engineering Pipeline

An end-to-end data engineering project demonstrating data extraction, transformation, loading, API development, data warehousing, cloud infrastructure, and business intelligence.

## Tech Stack

- PostgreSQL
- SQL
- Python
- FastAPI
- ETL
- Data Warehouse
- AWS / Azure
- Terraform
- Power BI

## Project Architecture

Source Data → PostgreSQL → FastAPI → ETL Pipeline → Data Warehouse → Cloud → Power BI
